How It Works

AST-aware compression understands code structure. Token dictionary maps patterns to short codes. Multi-pass optimization eliminates redundancies generic compressors miss.

VUCE File Format

VUCE_HEADER (16 bytes)  — magic "VUCE" + version + flags + dict_size
TOKEN_DICT (variable)   — key-value map
COMPRESSED_BODY         — AST nodes
RESTORE_TABLE            — whitespace/comment positions
VUCE_FOOTER (8 bytes)   — checksum + EOF

Commands

vuce_optimizer input.v -o output.vuce     # Compress
vuce_optimizer -d input.vuce -o output.v  # Decompress
