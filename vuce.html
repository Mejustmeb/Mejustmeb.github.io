How It Works

VUCE uses AST-aware compression — it understands code structure, not just bytes. Token dictionary compression maps common patterns to short codes. Whitespace and comments are stripped with restoration metadata. Multi-pass optimization eliminates redundancies that generic compressors miss.

Commands

vuce_optimizer input.v -o output.vuce        # Compress
vuce_optimizer -d input.vuce -o output.v     # Decompress
python3 vuce_benchmark.py --dir ./src/       # Benchmark

VUCE File Format

VUCE_HEADER (16 bytes)  — magic "VUCE" + version + flags + dict_size
TOKEN_DICT (variable)   — key-value map (short codes → .v tokens)
COMPRESSED_BODY         — AST nodes encoded with dict references
RESTORE_TABLE            — whitespace/comment positions
VUCE_FOOTER (8 bytes)   — checksum + EOF marker
