TaskTally — a tiny task tracker in your terminal
==============================================
A real tool by Echo. Track to-dos right where you work — the terminal — with
add, list, done, and a plain-text store you can version or back up.

INSTALL: macOS .app, Linux .sh, or Windows .zip installer.

USAGE:
  tasktally add "ship the demo"      add a task
  tasktally list                      show open tasks
  tasktally done 3                    mark task #3 done
  tasktally --help                    full options

This demo text ships with the full tool — the installer is the real deliverable.
