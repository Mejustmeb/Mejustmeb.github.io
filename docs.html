Parses C source — detects functions, loops, variables, types 2. Transpiles to .v language with SIMD annotations 3. Writes .vse package (encrypted .v intermediate) 4. Caches result (SHA-256 content hash) **Example**: ```bash vse encode fibonacci.c --keep-v --json ``` ### `vse run` — Transpile, Compile, Execute ```bash vse run input.c ``` Full pipeline: C → .v → ./v build → cc → binary → execute. ### `vse bench` — Benchmark C vs VSE ```bash vse bench input.c [--runs 5] ``` Compares: - Binary size (clang -O2 vs VSE-optimized) - Runtime (average of N runs) **Example output**: ``` Metric C (clang -O2) VSE .v Change ──────────────────── ─────────────────── ─────────────────── ───────────── Binary size 33,192 55,192 +66.3% Runtime (avg) 2.31ms 1.89ms -18.2% faster ``` ### `vse report` — Optimization Analysis ```bash vse report input.c ``` Shows detected optimization targets without compiling. ### `vse watch` — Auto-Recompile on File Change ```bash vse watch input.c [--run] ``` Polls the file every 500ms.
