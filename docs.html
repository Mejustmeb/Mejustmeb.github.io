1. Installation

macOS

cp ~/Desktop/VSE/vse /usr/local/bin/vse
chmod +x /usr/local/bin/vse
vse --help

Requirements: Python 3.9+, clang (Xcode CLT)

Ubuntu / Debian

sudo cp vse /usr/local/bin/vse
sudo chmod +x /usr/local/bin/vse
sudo apt-get install python3 clang build-essential
vse --help

Windows

# Install Python 3.9+ and LLVM/clang
# Copy vse to your PATH
python vse --help

Android (Termux)

pkg install python clang
python3 vse encode input.c

2. Quick Start

Create a C file:

#include <stdio.h>
int add(int a, int b) { return a + b; }
int main() { printf("%d\n", add(2,3)); return 0; }

Then:

vse encode hello.c      # Transpile C → .v → native binary
vse run hello.c         # Transpile → compile → execute
vse report hello.c      # Optimization analysis (free, always)
vse bench hello.c       # Benchmark C vs VSE
vse watch hello.c       # Auto-recompile on save

6. Feature Guides

Watch Mode

vse watch myprogram.c --run

Polls file every 500ms. Debounces 300ms after last write. --run executes binary after successful compile. Ctrl+C to stop.

Build Cache

vse cache          # Show entries + total size
vse cache clear    # Wipe all cached builds

Location: ~/.vse_cache/. SHA-256 content-hash keyed. Clear after VSE updates or OS compiler changes.

Benchmarking

vse bench myprogram.c --runs 10

Measures: binary size (clang vs VSE), runtime (average of N runs), speedup percentage. VSE averages 19.9% faster across 7 benchmark programs.

Cluster Compilation

python3 tools/cluster_orchestrator.py compile myprogram.v

Distributes across 9 nodes: macOS ARM64, Ubuntu x86_64, Debian 12, Windows x64, Linux ARM64, Android aarch64. 106 total cores, 10GbE interconnect.
